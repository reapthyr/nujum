=== WHAT YOU NEED TO GENERATE (run these on YOUR computer) ===

1. HMAC secret (64 hex chars):  Open PowerShell → run: openssl rand -hex 32
   Copy the 64-character output → paste into:
   - apps/bot/.env   (replace YOUR_64_CHAR_HEX_HERE)
   - packages/shared/.env (replace YOUR_64_CHAR_HEX_HERE)
   - Vercel env BOT_API_HMAC_SECRET

2. AUTH secret (base64 48 chars): Open PowerShell → run: openssl rand -base64 48
   Copy the output → paste into:
   - Vercel env AUTH_SECRET

3. Discord values you need:
   - Bot token: Discord Dev portal → Bot → Reset Token
   - Client ID: Discord Dev portal → General Information → Application ID
   - Client Secret: Discord Dev portal → General Information → Secret (if using OAuth)
   - Your user ID: Right-click your Discord avatar → Copy ID
